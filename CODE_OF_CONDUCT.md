# code of conduct

these are small repositories run by one person in her spare time, so this is short.

- be kind. disagree with the number, not with the person who posted it.
- no harassment, no slurs, no doxxing, no "which wallet is yours" games. addresses in
  these tools are public data; people are not.
- no shilling. issues and pull requests are for the code and the data, not for tokens,
  referral links or "alpha".
- assume good faith. a wrong label or a wrong percentile is a bug report, not a fight.

if something goes wrong, write to hello@alinaschanz.life. i read everything, and i will
remove comments or contributors that ignore the above, without a debate.
