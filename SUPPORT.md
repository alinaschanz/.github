# support

these are small tools kept by one person. here is how to get unstuck fast:

- **a wrong number or a crash**: open an issue with the exact command, what you expected and
  what you got. the templates ask for the rpc endpoint and the version because most bugs live there.
- **"how do i ..."**: the readme of each tool has a `use` section with every flag; the profile
  readme lists what each tool is for. if the answer is not there, an issue with the `question`
  label is fine, i turn the good ones into readme lines.
- **security**: see [SECURITY.md](SECURITY.md), please mail rather than post.
- **anything else**: hello@alinaschanz.life. i read everything; replies take a few days.

what i cannot help with: trading advice, "is this address a whale", and anything that needs an
api key. numbers, not calls.
